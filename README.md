# GPT TG Analytics

Телеграм-бот для мониторинга и анализа каналов. Позволяет получать последние сообщения из каналов и отправлять их на обработку в GigaChat (Sber).

## Что умеет

- Команда `/watch <username_канала>` — отслеживает канал
- Команда `/sum <username_канала> <текстовое задание>` — запрашивает последние сообщения из канала и отправляет их на суммаризацию/анализ в GigaChat
- Работает от имени вашего Telegram-аккаунта (MTProto) для чтения каналов
- Управление ботом через обычного Telegram-бота (Telegraf + Bot API)

## Структура

```
auth.js        — одноразовая авторизация вашего Telegram-аккаунта (MTProto-сессия)
config.js      — загрузка переменных окружения из .env
main.js        — запуск бота и MTProto-клиента
giga.js        — общение с API GigaChat (получение токена и запрос к модели)
.env           — секретные настройки (не коммитится)
```

## Быстрый запуск

### 1. Установите зависимости

```bash
npm install
```

### 2. Настройте `.env`

Создайте файл `.env` в корне проекта:

```env
TG_SESSION=
API_ID=ваш_api_id
API_HASH=ваш_api_hash
CLIENT_ID=ваш_client_id
CLIENT_SECRET=ваш_client_secret
GIGA_AUTH=ваш_giga_auth
TG_BOT_KEY=ваш_токен_бота
```

`API_ID` и `API_HASH` берутся на [my.telegram.org](https://my.telegram.org).  
`TG_BOT_KEY` — токен от [@BotFather](https://t.me/botfather).  
`TG_SESSION` заполнится автоматически после первого запуска авторизации (см. пункт 3).
`CLIENT_ID`, `CLIENT_SECRET`, `GIGA_AUTH` - берутся из GigaChat с авторизацией через Sber ID.

### 3. Авторизуйтесь (один раз)

```bash
node auth.js
```

Программа запросит:

- номер телефона (в формате `+79001234567`),
- код из SMS,
- пароль от двухфакторной аутентификации (если включён).

После успешного результата в консоли появится строка сессии, скопируйте её в переменную `TG_SESSION` в файл `.env`.

### 4. Запустите бота

```bash
node main.js
```

Бот подключится к вашему аккаунту и начнёт ждать команды.  
Бот должен быть админом одного из ваших тг каналов, чтобы получать по ним краткую сводку.
Напишите боту в Telegram по его username (тот, что регистрировали через @BotFather):

- `/watch @имя_канала`
- `/sum @имя_канала краткое резюме`

Бот будет работать **пока запущен процесс `node main.js`**. Для постоянной работы используйте `pm2`, `screen`, `tmux` или Docker.

## Остановить бота

Нажмите `Ctrl+C` в терминале, где запущен `node main.js`.  
Чтобы удалить бота из Telegram навсегда, обратитесь к [@BotFather](https://t.me/botfather) → `/mybots` → `Delete bot`.

## Безопасность

- Не делитесь строкой сессии (`TG_SESSION`) — она даёт полный доступ к вашему аккаунту Telegram.
- Нельзя передавать сторонним лицам `API_ID`, `API_HASH` и конфиги GigaChat.
